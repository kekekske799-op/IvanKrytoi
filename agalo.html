Частые вопросы

Коротко о главном

Это безопасно — запускать программу?

Да. Программа работает локально, никуда не отправляет данные и не требует интернета (кроме первой установки psutil). Весь код открыт — можешь проверить сам.

Нужны ли права администратора?

Для анализа — нет, но многие проверки (порты, firewall, /etc/shadow) без них не сработают. Для авто-исправлений (SMBv1, UAC, Firewall) — обязательно.

Программа что-то сломает?

Нет. Все исправления обратимы и стандартны: включить UAC, отключить SMBv1, включить Firewall. Никаких удалений файлов или правок реестра «наугад».

Работает на Windows 7?

Сканирование работает, но часть проверок (PowerShell-команды) может не сработать из-за старой версии. Лучше Windows 10/11.

Можно запускать на чужом компьютере?

Только с разрешения владельца. Несанкционированный анализ чужих систем в РФ преследуется по ст. 272 УК РФ.
